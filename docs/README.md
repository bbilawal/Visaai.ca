# Documentation lives in a separate repository

**→ [VISAAIDocs](https://github.com/bbilawal/VISAAIDocs)**

This directory is intentionally almost empty. On 2026-08-06 the **255 project
documents** that lived under `docs/` were moved to the documentation repository
so this repo carries code and only the control files a build or an agent
actually reads.

## Getting the docs

The two repositories are siblings; nothing in this repo requires the docs repo
to be present, and no build or test reads it.

```bash
git clone https://github.com/bbilawal/VISAAIDocs.git ../VISAAIDocs
```

## What stayed here, and why

Eleven markdown files remain, each for a concrete reason — not as a second copy
of the documentation:

| File | Why it stayed |
|---|---|
| `README.md` | Repository entry point |
| `CLAUDE.md`, `apps/web/CLAUDE.md` | Claude Code control files — instruction precedence |
| `apps/web/AGENTS.md` | Claude Code control file; **regenerated by `next dev`** |
| `PROJECT_STATE.md` | Read by the Claude completion-gate workflow |
| `apps/api/README.md`, `apps/web/README.md`, `infra/README.md` | Document the directory they sit in |
| `apps/api/scripts/README-load-test.md` | Sits with the script it explains |
| `apps/api/src/modules/prefill/fonts/README.md` | Sits with the font assets it covers |
| `docs/i18n/review/README.md` | **Generated build output** — `scripts/i18n/build-review-package.mjs` hardcodes `OUT_DIR = docs/i18n/review`, and VISAAIDocs commit `b551d5b` already recorded the decision that this package stays here |

Control files that stayed are kept short and point at the docs repo rather than
duplicating it.

## Known dangling references

Four **applied** Supabase migrations carry `docs/…` paths in their SQL comments:

```
20260627000000_risk_config.sql          → docs/eligibility-engine/CONFIG-RULES-PROPOSAL.md
20260627000001_document_intelligence.sql → docs/document-processing/GAPS.md
20260806000000_partner_api_platform.sql  → docs/partner-api/partner-api-security-review.md
20260806140000_beta_feedback.sql         → docs/beta-launch/feedback-process.md
```

These were **deliberately not updated.** The audit programme forbids editing a
migration that may already have executed, and all four have. They are comments
with no runtime effect; the documents they name are under `VISAAIDocs/` using
the mapping above. Any correction belongs in a new forward-only migration, not
an edit to a shipped one.
